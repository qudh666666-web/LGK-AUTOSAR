# 开源实现借鉴：2026-09-13

目标是让失败请求一次返回可行动的信息，减少 Agent 重查和输出量。

## 采用的思路

参考 [claude-autosar 的 bsw_write_ops.py](https://github.com/jasontaotao/claude-autosar/blob/main/packages/autoc/src/claude_autosar/cli/mcp_tools/bsw_write_ops.py)
中结构化 field/param_index 错误及简短校验报告的设计；
[包元数据](https://github.com/jasontaotao/claude-autosar/blob/main/packages/autoc/pyproject.toml)
声明 MIT。这里只借鉴接口思路，Rust 实现与测试独立编写，没有复制其源代码、注释、
测试数据或引入 Python/MCP 依赖。上游 main 会变化，以上是本日审阅入口。

LGK-AUTOSAR v0.3.9 落地范围：

- MODULE_REQUIRED / MODULE_NOT_FOUND：字段定位及当前工程候选；最多 8 个，
  不执行自动纠错，保留 module_name 与大小写兼容。候选来自已加载 DPA，
  不追加 SIP 扫描；候选提示是结合本工具模块命名需求的本地设计。
- DELIVERY_VERIFICATION_FAILED：默认严格模式的失败响应直接包含不一致、
  文件缺失、缺少/禁用文本及原请求 check_index（从 0 开始），无需先重跑
  enforce:false。最多 8 个失败项，每类文本最多 8 条，并返回总数/截断标志。
- 保留非零退出码和现有 CLI `Error:` / 包装器异常外层；JSON 位于错误详情中，
  不是成功 stdout。成功格式不变。其他错误尚未统一成这些结构化错误码。

## ECUC 语义差异：v0.3.10

参考 [claude-autosar 的 arxml_diff.py](https://github.com/jasontaotao/claude-autosar/blob/main/packages/autoc/src/claude_autosar/core/bsw/templates/arxml_diff.py)
按稳定路径输出 add/modify/delete 的思路，以及其
[diff_ops.py](https://github.com/jasontaotao/claude-autosar/blob/main/packages/autoc/src/claude_autosar/cli/mcp_tools/diff_ops.py)
提供结构化计数的接口形式。许可仍以该项目上述包元数据中的 MIT 声明为依据。

LGK-AUTOSAR 独立实现 `diff_ecuc`，没有复制 Python 源码、测试或引入 MCP/Python
依赖。实现只解析用户明确给出的两份工程内 ARXML，并针对一个模块建立
`模块/容器实例/参数或引用` 路径；返回值按路径稳定排序。为控制 Agent 上下文，
默认只返回 32 项，硬上限 256 项，单个值最多 512 个 Unicode 字符，并允许
用 `path_prefix` 继续缩小结果。重复路径会结构化拒绝，避免同名实例被静默配错。

本轮没有照搬上游的通用 XML 树转换、工作区数据库或 MCP 工具层。当前比较
范围是 ECUC 参数值和引用值；容器属性、注释、UUID、节点顺序和纯格式变化
不会列出。容器改名显示为删除加新增。这些边界让输出更小，也避免把整份
ARXML 送进模型上下文。

## ECUC 语义写入：v0.3.11

`set_ecuc_value` 是在上述语义路径思路上的本地扩展，不对应上游某段写入源码。
它没有引入通用 AUTOSAR 模型或新的运行依赖，而是组合当前 DPA 模块索引、
完整 XML 语义解析、保留原文的字节定位，以及 v0.3.8 已有的复核原文件与同目录
原子替换。

请求只需要模块、容器实例路径、参数或引用名、准确旧值和新值。工具同时用
解析后的 XML 树和原始文本位置确认同一个唯一目标，候选修改后再次解析并按
语义定位；注释中的伪 XML 不会成为可写目标。该设计避免向 Agent 返回行号和
XML 片段，同时保留 DaVinci 原文件的 BOM、换行、缩进、注释和节点顺序。

当前只修改已有的直接参数 `<VALUE>` 或引用 `<VALUE-REF>`。新增、删除、容器
结构变化和自闭合空值仍交给带原文前置条件的 `edit_file`，没有为了追求接口
数量扩大自动写入范围。
